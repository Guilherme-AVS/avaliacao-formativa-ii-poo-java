# Avaliação Formativa II

## Fundamentos de Java e Introdução à POO

A Avaliação Formativa II tem como objetivo verificar a aprendizagem dos conteúdos trabalhados nas Aulas 01 a 10 da disciplina de Programação Orientada a Objetos — Java.

## Conteúdos avaliados

- Introdução ao Java
- Tipos de dados, variáveis e operadores
- Estruturas condicionais
- Estruturas de repetição
- Métodos
- Strings
- Arrays
- Classes e objetos
- Construtores
- Encapsulamento

## Orientações

- Leia atentamente cada questão antes de iniciar a implementação.
- Utilize Java para resolver as questões de programação.
- Organize o código de forma clara e legível.
- Utilize nomes significativos para classes, métodos e variáveis.
- Priorize os conceitos trabalhados nas Aulas 01 a 10.
- O código deve ser compilável e executável.
- Teste suas soluções antes da entrega.

## Recursos não avaliados

Esta avaliação não contempla:

- `ArrayList`
- Collections
- Generics
- Herança
- Polimorfismo
- Classes abstratas
- Interfaces
- Exceções
- Arquivos
- Threads
- Padrões de projeto

## Entrega

A entrega deverá seguir as orientações definidas pelo professor.

Antes de entregar, verifique se:

- todos os arquivos possuem extensão `.java`;
- o nome da classe corresponde ao nome do arquivo;
- o código está compilando corretamente;
- os programas foram testados;
- não existem arquivos desnecessários na entrega;
- o código está organizado e legível.

## Objetivo da avaliação

Ao final desta avaliação, espera-se que o estudante seja capaz de desenvolver pequenos programas em Java utilizando os fundamentos da linguagem e construir classes com atributos, métodos, construtores e encapsulamento.
