# Gabarito — Think-Pair-Share — Aula 01

## Questão 1

O Java apresenta características como portabilidade, segurança, orientação a objetos, gerenciamento automático de memória e uma API extensa.

Para um sistema multiplataforma, a portabilidade é especialmente relevante porque o bytecode pode ser executado por uma JVM adequada à plataforma.

## Questão 2

- **JDK — Java Development Kit:** ambiente completo para desenvolvimento, incluindo compilador e ferramentas.
- **JRE — Java Runtime Environment:** ambiente destinado à execução das aplicações Java, incluindo bibliotecas e JVM.
- **JVM — Java Virtual Machine:** máquina virtual responsável por executar o bytecode Java.

## Questão 3

Quando uma classe é declarada como `public`, o nome do arquivo `.java` deve corresponder ao nome dessa classe pública.

Exemplo:

```java
public class Hello {
}
```

deve estar no arquivo:

```text
Hello.java
```

## Observação

O objetivo desta atividade é verificar se o estudante consegue explicar os conceitos com suas próprias palavras. Respostas equivalentes, conceitualmente corretas, devem ser consideradas.
