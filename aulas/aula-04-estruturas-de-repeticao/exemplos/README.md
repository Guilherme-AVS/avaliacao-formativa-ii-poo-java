# Exemplos — Aula 04

## Estruturas de Repetição em Java

| Arquivo | Conteúdo |
|---|---|
| `While.java` | Estrutura `while` |
| `DoWhile.java` | Estrutura `do-while` |
| `For.java` | Estrutura `for` |
| `ContadorEAumulador.java` | Contadores e acumuladores |
| `LoopsAninhados.java` | Repetições aninhadas |
| `Break.java` | Interrupção de um loop |
| `Continue.java` | Salto para a próxima iteração |
| `Tabuada.java` | Aplicação integrada com `for` |

Todos os exemplos são independentes.

Exemplo:

```bash
javac While.java
java While
```
