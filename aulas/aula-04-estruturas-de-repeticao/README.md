# Aula 04 — Estruturas de Repetição (Loops) em Java

## Tema

**Estruturas de Repetição (Loops) em Java**

Automatizando tarefas repetitivas com `while`, `do-while` e `for`.

## Objetivos

Ao final da aula, o estudante deverá ser capaz de:

- compreender o conceito de repetição;
- identificar a condição de parada de um loop;
- utilizar `while`;
- utilizar `do-while`;
- utilizar `for`;
- utilizar loops aninhados;
- utilizar `break`;
- utilizar `continue`;
- evitar loops infinitos;
- escolher a estrutura de repetição adequada para cada problema.

## Conteúdos

1. Revisão de estruturas condicionais
2. Conceito de repetição
3. `while`
4. `do-while`
5. `for`
6. Inicialização, condição e atualização
7. Contadores e acumuladores
8. Loops aninhados
9. `break`
10. `continue`
11. Loops infinitos e condições de parada
12. Think-Pair-Share
13. Desafio — encontre os erros

## Compilação

Entre na pasta de exemplos:

```bash
cd aulas/aula-04-estruturas-de-repeticao/exemplos
```

Compile:

```bash
javac For.java
```

Execute:

```bash
java For
```
