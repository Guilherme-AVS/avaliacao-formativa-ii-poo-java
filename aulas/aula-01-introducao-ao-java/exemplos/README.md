# Exemplos — Aula 01

## Introdução ao Java

Os exemplos desta pasta acompanham a Aula 01.

### Exemplo disponível

| Arquivo | Conteúdo |
|---|---|
| `Hello.java` | Estrutura básica de um programa Java e saída no console |

## Como executar

Entre na pasta dos exemplos:

```bash
cd aulas/aula-01-introducao-ao-java/exemplos
```

Compile:

```bash
javac Hello.java
```

Execute:

```bash
java Hello
```

Saída esperada:

```text
Olá, mundo!
```

## Estrutura estudada

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Olá, mundo!");
    }
}
```

Nesta aula, o foco é reconhecer a estrutura do programa e executar o primeiro código Java.
