# Aula 05 — Métodos em Java

## Tema

**Métodos em Java — organização, reutilização e decomposição de problemas**

A aula aprofunda o uso de métodos antes da introdução às classes e objetos.

## Objetivos

Ao final da aula, o estudante deverá ser capaz de:

- declarar e chamar métodos;
- compreender a assinatura de um método;
- utilizar métodos `void`;
- utilizar métodos com retorno;
- declarar parâmetros;
- passar argumentos;
- combinar parâmetros e valores de retorno;
- utilizar `return`;
- compreender escopo de variáveis;
- distinguir métodos `static` de métodos de instância em exemplos simples;
- utilizar sobrecarga de métodos;
- decompor um problema em métodos menores e reutilizáveis.

## Conteúdos

1. O que é um método
2. Declaração e chamada de métodos
3. Parâmetros e argumentos
4. Métodos `void`
5. Métodos com retorno
6. `return`
7. Assinatura de métodos
8. Escopo de variáveis
9. Métodos `static`
10. Sobrecarga de métodos
11. Decomposição de problemas
12. Boas práticas para métodos
13. Think-Pair-Share
14. Desafio — encontre os erros

## Compilação

Entre na pasta:

```bash
cd aulas/aula-05-metodos-em-java/exemplos
```

Compile um exemplo:

```bash
javac MetodoComRetorno.java
```

Execute:

```bash
java MetodoComRetorno
```
