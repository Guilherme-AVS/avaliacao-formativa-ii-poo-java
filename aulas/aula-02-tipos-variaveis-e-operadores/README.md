# Aula 02 — Tipos de Dados, Variáveis e Operadores em Java

## Tema

**Tipos de Dados, Variáveis e Operadores em Java**

Construindo a base para representar informações e resolver problemas.

## Objetivos

Ao final da aula, o estudante deverá ser capaz de:

- identificar os principais tipos de dados da linguagem Java;
- diferenciar tipos primitivos e não-primitivos;
- diferenciar variáveis, constantes e literais;
- declarar e inicializar variáveis;
- compreender escopo de variáveis;
- utilizar operadores aritméticos;
- utilizar operadores relacionais;
- utilizar operadores lógicos;
- utilizar incremento e decremento;
- utilizar atribuição composta;
- compreender divisão inteira e divisão decimal;
- compreender precedência e associatividade;
- criar programas simples com manipulação de variáveis.

## Conteúdos

1. Revisão da Aula 01
2. Tipos de dados
   - primitivos;
   - não-primitivos.
3. Variáveis
   - declaração;
   - inicialização;
   - atribuição;
   - nomenclatura;
   - escopo.
4. Constantes com `final`
5. Operadores
   - aritméticos;
   - relacionais;
   - lógicos;
   - incremento e decremento;
   - atribuição composta.
6. Precedência de operadores
7. Think-Pair-Share
8. Desafio: encontre os erros

## Compilação

Entre na pasta de exemplos:

```bash
cd aulas/aula-02-tipos-variaveis-e-operadores/exemplos
```

Compile um exemplo:

```bash
javac AtribuicaoComposta.java
```

Execute:

```bash
java AtribuicaoComposta
```

## Atenção

Nesta aula, `String` e arrays aparecem apenas para introduzir a diferença entre tipos primitivos e referências. O trabalho aprofundado com **Strings** será realizado posteriormente, e **arrays/ArrayList** também terão uma aula específica.
