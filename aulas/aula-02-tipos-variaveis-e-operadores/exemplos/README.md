# Exemplos — Aula 02

## Tipos de Dados, Variáveis e Operadores

Os exemplos desta pasta acompanham os tópicos apresentados na Aula 02.

| Arquivo | Conteúdo |
|---|---|
| `TiposPrimitivos.java` | Tipos primitivos |
| `TiposNaoPrimitivos.java` | `String`, arrays e objetos |
| `Variaveis.java` | Declaração, inicialização e atribuição |
| `EscopoVariaveis.java` | Variáveis locais, de instância e de classe |
| `Constantes.java` | Constantes com `final` |
| `OperadoresAritmeticos.java` | Operações e divisão inteira/decimal |
| `OperadoresRelacionais.java` | Comparações |
| `OperadoresLogicos.java` | `&&`, `||` e `!` |
| `IncrementoDecremento.java` | Pré e pós-incremento/decremento |
| `AtribuicaoComposta.java` | `+=`, `-=`, `*=`, `/=`, `%=` |
| `PrecedenciaOperadores.java` | Ordem de avaliação das expressões |

Todos os exemplos são independentes e podem ser compilados separadamente.

Exemplo:

```bash
javac OperadoresLogicos.java
java OperadoresLogicos
```
