# Exemplos — Aula 06

## Strings em Java

| Arquivo | Conteúdo |
|---|---|
| `DeclaracaoEConcatenacao.java` | Declaração, inicialização e concatenação |
| `TamanhoECaracteres.java` | `length()` e `charAt()` |
| `ComparacaoDeStrings.java` | `equals()` e `equalsIgnoreCase()` |
| `Substring.java` | Extração de partes de uma string |
| `BuscaEmString.java` | `indexOf()` e `lastIndexOf()` |
| `TransformacaoDeTexto.java` | Maiúsculas e minúsculas |
| `RemoverEspacos.java` | `trim()` e `strip()` |
| `Substituicao.java` | `replace()` |
| `VerificacaoDeConteudo.java` | `contains()`, `startsWith()`, `endsWith()`, `isEmpty()` e `isBlank()` |
| `Imutabilidade.java` | Imutabilidade de `String` |
| `ProcessamentoDeTexto.java` | Combinação de operações para resolver um problema |

Cada exemplo é independente.
