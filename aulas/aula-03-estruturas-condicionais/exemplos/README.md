# Exemplos — Aula 03

## Estruturas Condicionais em Java

| Arquivo | Conteúdo |
|---|---|
| `If.java` | Estrutura `if` |
| `IfElse.java` | Estrutura `if/else` |
| `ElseIf.java` | Estrutura `else if` |
| `CondicoesCompostas.java` | Operadores lógicos em decisões |
| `OperadorTernario.java` | Operador ternário |
| `Switch.java` | `switch`, `case`, `break` e `default` |
| `SwitchExpression.java` | `switch` expression |
| `SwitchComYield.java` | `switch` expression com `yield` |

Todos os exemplos são independentes.

Exemplo:

```bash
javac Switch.java
java Switch
```
