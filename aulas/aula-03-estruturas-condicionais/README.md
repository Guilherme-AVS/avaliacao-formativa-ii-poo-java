# Aula 03 — Estruturas Condicionais em Java

## Tema

**Estruturas Condicionais em Java — if, else, else if e switch**

## Objetivos

Ao final da aula, o estudante deverá ser capaz de:

- compreender a ideia de decisão em um programa;
- utilizar `if`;
- utilizar `if/else`;
- utilizar `else if`;
- combinar condições com operadores relacionais e lógicos;
- utilizar o operador ternário;
- utilizar `switch`;
- compreender `case`, `break` e `default`;
- diferenciar `switch` tradicional de `switch` expression;
- escolher a estrutura condicional adequada para cada situação.

## Conteúdos

1. Revisão de operadores
2. Tomada de decisão
3. `if`
4. `if/else`
5. `else if`
6. Condições compostas
7. Operador ternário
8. `switch`
   - `case`
   - `break`
   - `default`
9. `switch` expression
10. `yield`
11. Think-Pair-Share
12. Desafio — encontre os erros

## Compilação

Entre na pasta de exemplos:

```bash
cd aulas/aula-03-estruturas-condicionais/exemplos
```

Compile:

```bash
javac If.java
```

Execute:

```bash
java If
```

Para os exemplos de `switch expression`, utilize Java 14 ou superior.

## Observação

A aula utiliza as estruturas condicionais para preparar o estudante para os problemas de decisão que serão combinados com estruturas de repetição na Aula 04.
