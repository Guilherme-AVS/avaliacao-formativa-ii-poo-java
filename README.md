# Organização da Disciplina — Programação Orientada a Objetos (Java)

Repositório institucional da disciplina de **Programação Orientada a Objetos (POO)**.

Esta organização foi criada para centralizar os projetos desenvolvidos pelos estudantes ao longo dos semestres, mantendo uma estrutura organizada e reutilizável para futuras turmas.

---

## 🎓 Sobre a disciplina

A disciplina aborda o desenvolvimento de aplicações em **Java** utilizando os principais conceitos da **Programação Orientada a Objetos**, desde os fundamentos da linguagem até a aplicação de padrões de projeto.

### Principais conteúdos

- Fundamentos da linguagem Java
- Classes e objetos
- Encapsulamento e modificadores de acesso
- Construtores
- Associação entre classes
- Herança
- Polimorfismo
- Classes abstratas
- Interfaces
- Pacotes e organização de código
- Tratamento de exceções
- Coleções e Generics
- Arquivos e fluxos de I/O
- Threads e concorrência
- Padrões de Projeto (GoF e GRASP)
- Desenvolvimento de um sistema orientado a objetos

---

## 📁 Organização dos projetos

Cada semestre possui seus próprios repositórios, permitindo preservar o histórico das turmas sem misturar os projetos.

### Estrutura recomendada

```text
POO-Java/
├── 2026.2/
│   ├── projeto-grupo-01/
│   ├── projeto-grupo-02/
│   └── ...
├── 2027.1/
│   ├── projeto-grupo-01/
│   └── ...
└── README.md
```

> Os nomes e a organização dos repositórios podem ser adaptados conforme a necessidade de cada turma.

---

## 🚀 Projeto Integrador

Ao longo da disciplina, os estudantes desenvolverão incrementalmente um **Sistema Orientado a Objetos em Java**.

O projeto passa pelas seguintes etapas:

1. **Proposta e Escopo**
2. **Modelagem de Classes**
3. **Implementação Parcial**
4. **Implementação Avançada**
5. **Padrões de Projeto**
6. **Defesa Técnica**

Cada etapa acompanha os conteúdos trabalhados em aula e contribui para a construção do sistema final.

## 📌 Boas práticas

Durante o desenvolvimento dos projetos, espera-se que os estudantes:

- Utilizem nomes significativos para classes, métodos e atributos.
- Apliquem os princípios de orientação a objetos trabalhados na disciplina.
- Mantenham o código organizado e legível.
- Utilizem controle de versão desde o início do projeto.
- Realizem commits descritivos e frequentes.
- Documentem decisões técnicas relevantes.
- Mantenham o README dos projetos atualizado.
- Evitem código duplicado.
- Testem as funcionalidades desenvolvidas.
- Trabalhem de forma colaborativa utilizando GitHub.

---

## 🌱 Evolução por semestres

Esta organização foi criada para permanecer ativa ao longo dos semestres.

A cada nova turma, será criado um novo conjunto de repositórios, preservando os projetos e o histórico das turmas anteriores.

Assim, a organização funciona como um **portfólio acadêmico contínuo dos projetos desenvolvidos na disciplina**.
